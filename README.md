# Grapez Analytics Agents
### Google for Startups AI Agents Challenge 2026

A multi-agent system that connects to a client's Google account and automatically **diagnoses + configures their entire marketing analytics ecosystem** — GA4, GTM, and Google Ads — in minutes instead of days.

---

## The Problem

Setting up a client's measurement ecosystem (GA4 + GTM + Google Ads) takes consultants **1–3 days of manual work** per client. Errors are frequent and repetitive. Grapez Studio handles this for e-commerce clients — this system 3x's their capacity with the same team.

## The Solution

A system of 6 specialized AI agents that work in parallel:

| Agent | Role |
|---|---|
| **Planner Agent** | Orchestrates the workflow, interprets consultant goals |
| **GA4 Agent** | Diagnoses and configures Google Analytics 4 properties |
| **GTM Agent** | Audits Google Tag Manager containers, tags, triggers |
| **Google Ads Agent** | Reviews conversion tracking and GA4 linkage |
| **Web Analyzer Agent** | Crawls the client's website with Playwright to detect tracking implementations |
| **Implementation Agent** | Executes approved fixes via APIs with human confirmation at each step |

## Tech Stack

- **Google ADK** — multi-agent orchestration
- **Gemini 3 Flash Preview** — model for all agents
- **Agent Engine** — managed agent runtime (Google Cloud)
- **A2UI** — dynamic UI components generated by the agent
- **Next.js 15** — frontend
- **Firestore** — client + token storage
- **Cloud Run** — frontend hosting
- **Playwright** — browser automation for web analysis
- **GA4 Admin API + GTM API + Google Ads API** — full read/write via Python

## Setup

```bash
# Clone
git clone https://github.com/grapez/grapez-analytics-agents

# Backend (agents)
pip install -r requirements.txt
playwright install chromium
cp .env.example .env
# → fill in .env with your keys

# Frontend
cd frontend
npm install
npm run dev

# Deploy agents to Agent Engine
adk deploy agent_engine --env_file .env --region=us-central1 agents/planner_agent
```
